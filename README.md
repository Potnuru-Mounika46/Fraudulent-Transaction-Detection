# Fraudulent Transaction Detection

## Project Overview

This project aims to detect fraudulent financial transactions using Machine Learning techniques. The system analyzes transaction data and classifies transactions as either legitimate or fraudulent, helping financial institutions reduce financial losses and improve security.

## Objectives

* Identify fraudulent transactions from transaction records.
* Build a machine learning model for fraud detection.
* Improve transaction security through predictive analytics.
* Evaluate model performance using standard classification metrics.

## Dataset

The project uses a transaction dataset containing various features such as:

* Transaction amount
* Transaction type
* Account information
* Balance details
* Fraud labels

## Machine Learning Algorithms

The following algorithms were evaluated:

* Logistic Regression

* XGBoost (if used)

## Performance Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC Score

## Results

The developed model successfully identifies fraudulent transactions with high accuracy and helps minimize financial risks by detecting suspicious activities in real time.
